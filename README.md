# MiniBlog - React + TypeScript (Vite)

Ứng dụng web MiniBlog xây dựng phục vụ bài kiểm tra giữa kỳ môn Lập trình Web.

## Công nghệ sử dụng
- **React 18/19** với **Vite**
- **TypeScript** (Static typing, Interface type checking)
- **React Router DOM** (Client-side routing, Protected Route)
- **Fetch API thuần** (Async/Await, xử lý bất đồng bộ)
- **HTML5 LocalStorage** (Lưu trữ bài viết cục bộ và phiên đăng nhập)
